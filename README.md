# LumiSpace - Jasa Dekorasi Landing Page

Landing page mini website untuk **LumiSpace** (Jasa Dekorasi Premium di Palangka Raya).

🌐 **Live Demo:** [https://solusilokal.github.io/LumiSpace/](https://solusilokal.github.io/LumiSpace/)

---

## 🚀 Fitur Utama
- **Hero Section:** Logo brand, tagline, tombol konsultasi, dan direct link (Instagram, TikTok, Google Maps).
- **Cerita Kami & Jejak Langkah:** Kisah awal dan sejarah berdirinya LumiSpace.
- **Layanan Kami:** Wedding Decor, Engagement, Birthday Party, Photo Backdrop.
- **Katalog Karya:** Galeri portofolio interaktif dengan Lightbox viewer (zoom, geser, tutup).
- **Pilihan Paket:** Informasi paket dekorasi lengkap dengan estimasi harga yang rapi dan terstruktur.
- **Lokasi Workshop:** Peta dan navigasi langsung ke Google Maps.
- **Tanya Jawab (FAQ):** Accordion FAQ interaktif.
- **Testimoni Klien:** Review dan rating kepuasan pelanggan.
- **Form Diskusi / Booking:** Form langsung terintegrasi otomatis dengan pesan WhatsApp admin.
- **Sticky CTA & Share Modal:** Tombol floating konsultasi cepat dan modal berbagi link ke media sosial.

---

## 🛠️ Cara Menjalankan & Preview Lokal

### Cara 1: Menggunakan File Batch (Paling Mudah)
Cukup klik ganda (*double click*) file:
`run-preview.bat`

### Cara 2: Lewat Terminal / Command Prompt
```bash
# 1. Install dependensi (jika belum)
npm install

# 2. Jalankan dev server
npm run dev
# atau di Windows PowerShell:
npm.cmd run dev
```

Aplikasi akan terbuka otomatis di browser pada:
`http://localhost:3000`

### Build untuk Produksi
```bash
npm run build
```
File hasil build statis akan berada di dalam direktori `dist/`.
